**JITJAT (Just-In-Time / Jack-of-All-Trades)** replaces static, token-heavy `.SKILL.md` prompt files with a biological, self-compacting cognitive hypergraph backed by memory-mapped SQLite WAL and `/dev/shm` volatile RAM capsules.

## What's New in v2.0 (The Elastic Wisdom Breakthrough)

1. **Two-Way Elastic JAT/JIT Allocation (5% to 40%):**
   Instead of a rigid 80/20 split, new capabilities start with a high conscious JAT allocation (25%–40%). As the agent repeatedly succeeds on a task, procedural bulk is offloaded to `/dev/shm` JIT muscle-memory capsules and the JAT anchor shrinks down to **5%–10%**, retaining only pure **Wisdom Heuristics** and **Negative Invariants ($INV$)**. If an unexpected failure occurs, JAT elastically re-expands for conscious deliberation.
2. **Compound Faculty Archetypes:**
   When multiple faculties co-activate to solve a multi-step job, JITJAT automatically binds them into a reusable **Compound Archetype**, eliminating recurring planning overhead on recurring workflows.
3. **Sub-2.5ms Zero-Token Traversal:**
   Cortical lookups execute in **< 0.5 ms to 2.1 ms** at rest with **0 prompt tokens consumed** until the exact JIT synapse is mounted.
